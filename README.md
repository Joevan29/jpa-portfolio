# JPA.DEV — Brutalist Portfolio

A premium, highly interactive, 100/10 brutalist portfolio built for **Joevan Pramana Achmad**, a Full Stack Backend & Cloud Engineer. Engineered with chaos, this portfolio goes beyond standard web design by introducing physics-based interactions, mechanical sound effects, and secret developer easter eggs.

## ⚡ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI Library:** React
- **Styling:** Tailwind CSS
- **Animations & Physics:** Framer Motion
- **Typography:** DM Sans, Syne, JetBrains Mono

## 🛠️ Key Features

### 1. Neo-Brutalist Aesthetics
- High-contrast color palette (Ink Black, Neon Green, Acid Yellow, Deep Purple).
- Sharp borders, solid shadows (`shadow-brutal`), and explicit typography.
- Dynamic vertical gradient background that smoothly fades from the Hero section to the Footer.

### 2. Interactive Sections
- **Hero:** Interactive draggable stickers, a live GitHub Activity widget fetching real-time commits, and an "Open to Work" pulse badge.
- **The Stack:** A 4-column tech arsenal grid with subtle rotations, hover animations, and dynamic counters.
- **Credentials:** A physics-enabled, draggable "receipt card" canvas. Users can literally throw the certification cards around the screen.
- **Selected Works:** Project cards featuring detailed "Case Study" modals outlining the *Problem*, *Approach*, *Result*, and *Key Metrics*.
- **The Journey:** A clean, vertical timeline showcasing professional experience.

### 3. The "Hire Me" Minigame
An evasive CTA button in the Navbar that flees from the cursor when hovered. After 3 "misses", it finally surrenders, changes color, and allows the user to click it — smoothly scrolling to the Contact section.

## 🕵️‍♂️ Developer Easter Eggs

This portfolio hides several secrets tailored specifically for technical recruiters and fellow senior developers:

1. **Terminal Mode:** Press `` ` `` (backtick) anywhere to open a fully functional, interactive terminal. Commands include: `whoami`, `skills`, `projects`, `contact`, `clear`, `exit`.
2. **X-Ray Mode:** Hold the `Alt` (or `Option`) key to strip the website of its styling and reveal the raw CSS Box Model wireframes in neon green outline.
3. **Chaos Mode:** Type `c-h-a-o-s` on your keyboard to trigger a screen-shaking, glitching, color-inverting chaos event.
4. **DevTools Secret:** Open the browser's Inspect Element Console to find a giant ASCII art logo and a hidden welcoming message.
5. **Tab Hijacker:** Switch to another browser tab, and the page title will automatically change to a custom message (`"Hey, come back! 😢"`).
6. **Mechanical Cursor:** Custom trailing dot cursor that plays mechanical "click" and "clack" sound effects when clicking links or dragging items.

## 📱 Mobile & SEO Optimized

- Fully responsive padding and grid structures using CSS `clamp()` and Tailwind breakpoints.
- Complex desktop interactions (like draggable canvas) gracefully degrade to clean, readable static grids on mobile devices.
- Comprehensive SEO metadata, including Open Graph images and `JSON-LD` Person schema for rich Google Search indexing.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Joevan29/jpa.dev.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
